# Packaged data

All coordinates are GRCh38.

`enhancers/atlas/` contains the 52 mappability-filtered Atlas sets used by the revised common-universe analysis. `enhancers/scenhancer/` contains the 165 non-unique scEnhancer sets selected by the reproduced manuscript `part` rule. The manifests are authoritative and record the ordering, file name, interval count, summed interval length, and compressed-file SHA-256 checksum.

`dnvs/` contains the cohort-level noncoding DNM BED files generated by the reproduction workflow at CADD thresholds 0, 10, 15, and 20. These files contain genomic coordinates only; they do not contain sample identifiers.

`tad/` contains the GSE77565 cortical-plate and CNCC TAD resources plus the PhenoSV-derived gene BigBed used to enumerate protein-coding genes. The CNCC resource is used for craniofacial analyses because the historical PhenoSV TAD file referenced by the original notebooks is no longer available.
